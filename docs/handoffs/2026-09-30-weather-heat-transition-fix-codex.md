# 폭염 전환 시 아지랑이 가속 버그 수정 — Codex 요청 (Studio → Codex)

2026-09-30 · 작성: Claude · 대상: Game Codex · 선행: `2026-09-30-weather-heat-and-transition-tuning-codex.md` 적용본

사용자 확인 결과: 폭염 아지랑이(진폭 [2.0, 1.4] / 파장 100 / 속도 20)와 전환 시간(3.0 / 2.5 / 2.0s)은 **승인**. 아래 버그 하나만 수정한다. 아지랑이가 트랙(와 foreground)만 왜곡하고 차량·자국·이펙트는 왜곡하지 않는 현재 방식은 **그대로 유지**(화면 복사 방식으로 바꾸지 않음 — 사용자 결정).

## 1. 현상

폭염 → 다른 날씨(또는 그 반대)로 전환하는 3초 동안 아지랑이 무늬가 빠르게 쓸려 간다.

## 2. 원인 (Claude 읽기 전용 확인 — 실제 코드로 재확인 필요)

`weather_grade.gdshader`의 노이즈 좌표는 `(px + vec2(0, weather_time * heat_speed)) / heat_wavelength`이다. `WeatherVisualController`는 전환 중 grade의 **모든 키를 보간**하므로 `heat_speed`(20 ↔ 12)와 `heat_wavelength`(100 ↔ 50, `NEUTRAL`·비·눈 프로필 값)도 3초 동안 변한다. `weather_time`이 큰 값이라 두 값이 조금만 변해도 노이즈 좌표가 크게 이동 → 빠르게 흐르는 것처럼 보인다.

## 3. 요청

- 전환 중 **`heat_amplitude`만 보간**(0 ↔ 폭염 값)하고, `heat_speed`·`heat_wavelength`는 보간하지 않는다:
  - 폭염으로 들어갈 때: 전환 시작 시 폭염 값으로 즉시 설정(진폭이 0에서 시작하므로 보이지 않음).
  - 폭염에서 나갈 때: 진폭이 0이 될 때까지 폭염 값을 유지.
  - 폭염이 아닌 날씨끼리의 전환: 진폭 0이라 영향 없음.
- 구현 방식은 Codex 판단(예: 보간 제외 키 목록, 또는 흐름 위상을 CPU에서 적분해 uniform으로 전달). 셰이더 샘플 수·부하는 늘리지 않는다.
- 전환 도중 재전환(폭염 → 비 → 폭염 등)에서도 무늬가 튀지 않는지 확인.

## 4. 검증·보고

- focused: 폭염 진입·이탈·재전환 중 `heat_speed`/`heat_wavelength` 불변, 진폭만 보간. 기존 검사 유지 통과.
- 사용자 확인용 격리 실행(맑음 → 폭염 → 비 → 폭염 → 맑음).
- 공통 인계 형식으로 짧게 보고. 다른 날씨 값·게임 로직·저장 데이터 변경 금지, 승인 없는 commit 금지.
