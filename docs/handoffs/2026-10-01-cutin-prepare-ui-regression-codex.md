# 컷인 사전 준비로 생긴 UI 회귀 수정 — Codex 요청

2026-10-01 · 작성: Claude (Game 읽기 전용 확인) · 대상: Game Codex · 선행: `docs/TALENT_ACTIVATION_SPIKE_INVESTIGATION.md` 적용본(미커밋)

## 0. 사용자 보고

방치형 게임이라 경기 진행과 관계없이 **관리 버튼과 메뉴를 언제나 조작할 수 있어야 한다.** 컷인 사전 준비 적용 후:
- 경기 시작 전 화면 좌측 UI(플레이어 상태 HUD)가 늦게 나온다.
- **관리 버튼이 카운트다운 동안 아예 보이지 않는다**(사용자 녹화: 리그 맵에서 다음 경기 선택 → 카운트다운 3·2·1 내내 관리 버튼 없음, 출발 후 다시 표시).

게임 조작에 영향을 주는 변경은 범위 밖이었다. 원래 동작으로 되돌려야 한다.

## 1. 원인 (읽기 전용 확인, `git diff` 기준)

`RaceManager._start_race_with_track()`에서 `_race_state = RaceState.COUNTDOWN`이 원래 자리(기존 `_update_season_map_button()` 호출 직전)에서 **`await _prepare_race_cutin_visuals(...)` 뒤로 이동**했다.

1. 기존 자리의 `_update_season_map_button()`(현재 약 26238행)이 이제 **SETUP 상태에서 호출**된다. 이 함수는 `_race_state != RaceState.SETUP`일 때만 관리 버튼을 보이게 하므로 버튼이 숨겨지고, COUNTDOWN 전환 뒤(26286행 이후)에는 다시 호출되지 않아 **출발 전까지 계속 숨겨진다.**
2. 같은 함수는 숨김 분기에서 **`_close_management_popup()`을 호출**한다. 방치형으로 경기가 자동 진행될 때 사용자가 관리 메뉴를 열어 둔 상태라면, 새 경기 SETUP 중에 **열려 있던 관리 창이 닫힐 수 있다**(새로 생긴 위험 — 확인 필요).
3. `_refresh_player_race_status_hud(true)` 등 좌측 HUD·리더보드 갱신이 컷인 준비(보고 132~148ms + 렌더 대기 프레임) 뒤로 밀려 늦게 나온다.

## 2. 수정 방향 (권장)

**컷인 준비가 경기 상태·UI 순서를 바꾸지 않게 한다.**

1. `_race_state = RaceState.COUNTDOWN`과 그 뒤 UI 갱신(관리 버튼, 좌측 HUD, 리더보드, 카운트다운 표시 등)을 **변경 전 위치·순서로 원복**한다. Static Ribbon·날씨 준비(변경 전부터 있던 SETUP 대기)는 그대로.
2. 컷인 준비는 **COUNTDOWN 시작과 동시에 비동기로 진행**하고 경기 상태를 막지 않는다. 카운트다운(약 3초)이 준비 시간(132~148ms)보다 충분히 길고, 재능은 출발 후에만 발동한다.
   - 준비가 끝나기 전에 발동하면 이미 있는 **정지 이미지 대체**를 사용(현재 실패 처리와 같음).
   - 레이스 취소·재시작·트랙 교체 시 진행 중인 준비 취소·정리(generation 규칙 유지).
   - 준비의 동기 처리 구간(보고 최대 ≈10.6ms)은 카운트다운 중에 발생해도 조작에 영향이 없는지 확인. 필요하면 여러 프레임으로 분산.
3. 준비 코드가 `_race_state`, 관리 버튼·팝업, HUD 표시를 직접 바꾸지 않게 한다.

대안(권장하지 않음): 관리 버튼 표시 조건에서 SETUP 제외를 없애는 것은 변경 전부터 있던 동작을 바꾸므로, 사용자 별도 승인 없이 하지 않는다.

## 3. 검증

- 변경 전(HEAD `1922e42`) 대비 동일하게: 카운트다운 시작 시점에 관리 버튼·좌측 HUD·리더보드 표시, SETUP 길이(Static Ribbon·날씨 준비 외 증가 없음).
- **관리 창을 열어 둔 상태로 다음 경기가 자동 시작**될 때 창이 닫히지 않는지(변경 전 동작과 비교). 리그 맵·설정 등 다른 팝업도.
- 카운트다운 중 관리 버튼 클릭·메뉴 조작 가능.
- 컷인 개선 효과 유지: 같은 조건 A(MP4 포함) 발동 후 2초 최대 프레임이 수정 전 수준(≈18ms)인지, 준비 미완료 시 정지 이미지 대체.
- 공통 인계 형식으로 보고. 게임 규칙·저장 데이터 변경 금지, 승인 없는 commit 금지.
