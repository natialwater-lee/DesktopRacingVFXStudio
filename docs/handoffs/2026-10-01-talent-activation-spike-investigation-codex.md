# 재능 동시 최초 발동 프레임 지연(50~70ms) 원인 분리 — Codex 요청

2026-10-01 · 작성: Claude · 대상: Game Codex

## 0. 배경

재능 VFX를 Game에 적용할 때마다 **8대 동시 최초 발동 프레임**에서 큰 지연이 관측됐다. 매번 MP4 컷인이 같은 순간에 시작돼 원인이 분리되지 않았다.

| 재능 | 관측 (debug GL, 20대) |
|---|---|
| 나이트 비전 | 5대 20.97ms / 8대 51.15ms |
| 광합성(재제작) | 8대 51~59ms |
| 레인 서퍼 | 8대 50.46ms |
| 바람의 레이서 | 8대 70.14ms |

재능이 늘수록 계속 나타날 수 있으므로 **원인 분리 측정**을 요청한다. 이 문서는 Claude가 Game을 읽기 전용으로만 보고 작성했으며, 아래 가설은 검증되지 않았다.

## 1. 요청: 측정으로 원인 분리 (수정 전 단계)

같은 fixture(20대, 같은 트랙·날씨·seed)에서 8대 동시 최초 발동 프레임을 다음 조건별로 측정하고, 가능하면 발동 프레임 안의 구간별 CPU 시간(재능 판정 / HUD / 컷인 / VFX `start_vehicle_effect`·renderer 생성 / 텍스처·재질 최초 사용)을 기록해 달라.

| 조건 | 목적 |
|---|---|
| A. 현재 그대로 | 기준 |
| B. 컷인(MP4) 재생 끔 | 컷인 몫 |
| C. 재능 VFX package 끔(legacy·package 모두 없이 판정만) | VFX 몫 |
| D. 같은 재능 **두 번째** 동시 발동(재발동) | 최초 1회 비용(리소스·셰이더 준비)인지 매번 비용인지 |
| E. 발동 시각을 1프레임씩 어긋나게(가능하면) | 동시성 몫 |

## 2. 가설 (Claude, 미검증)

- **MP4 컷인 최초 디코더 준비**가 가장 유력(모든 재능 공통, 재능별 VFX 구성과 무관하게 비슷한 크기).
- VFX 쪽 후보: CPU 호환 파티클 백엔드의 **스프라이트 풀 생성**(바람의 레이서는 차량당 최대 11, 8대 ≈ 90개 노드를 한 프레임에 생성), package 텍스처·ADDITIVE 재질의 **GL 최초 사용 준비**. 바람의 레이서가 가장 큰(70ms) 것은 풀 크기와 관련 있을 수 있다.
- Solo Run은 SETUP 렌더 준비 경로가 있어 비교 기준이 될 수 있다.

## 3. 원인별 대응 방향 (측정 후 판단)

- 컷인: 경기 SETUP에서 해당 레이스에 편성된 재능의 컷인 디코더 사전 준비, 또는 동시 발동 시 컷인 1개만 재생 등 — Game 정책 판단.
- VFX 풀 생성: 경기 SETUP에서 편성된 재능 package의 renderer/풀 사전 생성(재사용), 또는 발동을 프레임 분산.
- GL 최초 사용: 트랙 날씨처럼 SETUP에서 실제 가시 렌더로 준비.
- 어떤 경우든 package·Studio 계약 변경이 필요하면 먼저 알려 달라.
