# GPT 아트 요청 — 절대 방어(Absolute Defense) VFX v2, 3장

아래 구분선 아래 내용을 그대로 GPT에 전달한다. **첨부:** ① 레퍼런스 이미지(차 양옆으로 흐르는 액체형 파란 에너지 막), ② 현재 게임 캡처(직선 육각 벽 + 좁은 U자). ②에는 "이 형태를 바꾸려는 것"이라고 덧붙인다. 설계: `docs/superpowers/specs/2026-10-02-talent-absolute-defense-design.md` 8절.

---

Desktop Idle Racing은 탑뷰 레이싱 게임이고, 실제 차량 크기는 약 24×49px입니다. 이 게임의 **절대 방어 재능** 경기용 VFX를 다시 만들려고 합니다. PNG 3장을 부탁드립니다.

주제는 **선두권 차가 뒤차의 추월을 막아 내는 에너지 방어막**입니다. 기존 버전(두 번째 첨부)은 육각 무늬가 들어간 곧은 직사각형 벽이라 장식 프레임처럼 보였습니다. 이번에는 첫 번째 레퍼런스처럼 **살아서 흐르는 액체형 에너지 막**으로 만들어 주세요.

전체 실루엣은 아래와 같습니다. 차 옆에 붙어 시작한 막이 뒤로 갈수록 바깥으로 벌어지고, 차 뒤의 **넓고 얕은 호**와 이어져 뒤를 막습니다.

```
   ( ▓▓ )        ← 좌우 곡면 막 (1번 이미지, 오른쪽 것만 제작)
  (  ▓▓  )
 (   ▓▓   )
╲___________╱    ← 뒤 방어 전면 (2번 이미지)
```

## 공통 조건

- 시점: **완전한 탑뷰**이고 차량 전방이 이미지 **위쪽**입니다.
- 스타일: 실사풍으로 발광하는 **액체형 에너지 막**. 반투명한 면에 밝은 가장자리를 두고, 결이 앞에서 뒤(이미지 위→아래)로 흐르는 물결·실 가닥 질감을 넣어 주세요.
  - **육각형·격자·기하학 무늬는 넣지 마세요.**
  - 자로 그은 듯한 직선 테두리, 만화풍 외곽선, 매끈한 단색 도형, 픽셀아트도 피해 주세요.
- **가산 합성(ADDITIVE)용** PNG RGBA, straight alpha입니다. 배경은 완전 투명하게 하고, 사방에 알파 0인 여백을 2px 이상 남겨 주세요.
- 색: 하늘빛 청록 (0.35, 0.8, 1.0). 가장 밝은 가장자리는 흰빛 (0.9, 0.98, 1.0)으로 해 주세요. 빨강·주황·초록·보라는 쓰지 마세요. 투명한 부분의 RGB는 (0.5, 0.85, 1.0)로 채워 주세요.
- 게임에서는 약 0.1배로 아주 작게 표시됩니다.
  - **바깥 가장자리 빛은 8~12px 이상 굵고 밝게** 해 주세요.
  - 안쪽 면은 옅게(알파 0.15~0.35) 해 주세요.
  - 흐름 결은 큰 덩어리 3~5개 정도로 단순하게 해 주세요.
  - 작은 점이나 반짝임은 넣지 마세요.
- 차량, 바퀴, 노면, 그림자, 글자, 워터마크는 넣지 마세요.

## 1) `talent_absolute_defense_side_curtain_r_a.png` / `_r_b.png` — 각 192×480 (2장)

- **역할:** 효과가 지속되는 동안 차 **오른쪽**에 서는 에너지 막을 위에서 본 모습입니다. 왼쪽 막은 이 이미지를 좌우 반전해서 씁니다. A와 B를 번갈아 보여 주어 결이 흐르는 것처럼 보이게 합니다.
- **구도:** 위에서 아래로 내려가는 **곡선 띠**입니다.
  - 띠 중심선은 위쪽 (40, 24) 근처에서 시작해 아래쪽 (150, 440) 근처에서 끝납니다.
  - 위쪽 2/3는 거의 곧게 조금씩 오른쪽으로 기울고, 아래로 갈수록 더 오른쪽으로 휘어집니다. 활처럼 바깥으로 벌어지는 모양입니다.
  - 띠 폭은 약 28~34px이고, 아래쪽이 조금 더 넓어도 됩니다.
  - **오른쪽(바깥) 가장자리**를 가장 밝게 해 주세요. 가장자리 선 굵기는 8~12px이고, 테두리가 물결처럼 살짝 출렁여야 합니다.
  - **왼쪽(안쪽, 차 쪽) 가장자리**는 흐리게 번지며 사라지게 해 주세요.
  - 위 끝은 약 60px에 걸쳐, 아래 끝은 약 40px에 걸쳐 알파 0으로 부드럽게 사라지게 해 주세요. 잘린 것처럼 보이면 안 됩니다.
- **A와 B:** 띠의 형태와 위치는 **완전히 같게** 하고, 안쪽 흐름 결과 가장자리 출렁임 위치만 다르게 해 주세요. B는 결이 반 칸 아래로 흘러간 느낌이면 됩니다.
- 알파 최대값은 가장자리에서 약 0.9입니다.

## 2) `talent_absolute_defense_rear_front.png` — 512×176

- **역할:** 차 뒤를 **넓게 가로막는 방어 전면**을 위에서 본 모습입니다. 평소에는 은은하게 일렁이고, 뒤차의 추월을 막아 낸 순간 크게 부풀며 번쩍입니다. 이 재능의 핵심 연출입니다.
- **구도:** **얕고 넓은 호**입니다. 아래(뒤)로 볼록하고 깊은 U자가 아닙니다.
  - 양 끝은 (24, 24)과 (488, 24) 근처이고, **끝부분이 위쪽(앞)으로 살짝 휘어 올라갑니다.** 좌우 막의 아래 끝과 이어지는 자리입니다.
  - 가장 아래 중심은 (256, 120) 근처입니다.
- **띠:** 중앙 두께는 약 34px이고 양 끝으로 갈수록 14px 정도로 가늘어집니다.
  - **아래(뒤) 가장자리**가 가장 밝아야 합니다. 굵기 10~12px이고 살짝 출렁이는 선입니다. 뒤차를 향한 방어선입니다.
  - 위(차 쪽) 가장자리는 흐리게 번지게 해 주세요.
  - 안쪽 면에는 중앙에서 좌우로 퍼져 나가는 물결 결을 넣어 주세요.
  - 띠 둘레에 부드러운 청록 번짐이 있으면 좋습니다.
  - 양 끝 약 30px은 알파 0으로 사라지게 해 주세요.
- 알파 최대값은 약 0.95입니다.
