| 피드백 | 원인 (확인 결과) |

## 4. 물보라 띠(wake) — Game 신규 표현 (Codex)

C의 MultiMesh 리본 엔진(연속 획, 누적 거리 UV, 셰이더 감쇠)을 재사용해 **각 뒷바퀴가 지나간 경로에 부드러운 물안개·눈가루 띠**를 깐다.

| 항목 | 비 | 눈 |
|---|---|---|
| 발생 조건 | 날씨가 비·눈이고 `is_weather_tire_visual_active()`(이동 중·정지 아님·피트 아님·억제 아님). **직선 포함 상시**(코너 전용 아님) | 같음 |
| 조각 간격 | 0.05s | 0.05s |
| 수명 | 0.5s | 0.7s |
| 폭 | 타이어 폭(36) → 수명 끝 **×3.5** (화면 ≈3.4 → 12px), smoothstep | 36 → **×3.0** |
| 알파 | 0.35, 생성 직후 0.05s 페이드 인 → 끝 40% 페이드 아웃 | 0.5 |
| 색 | (0.85, 0.90, 0.97) | (1.0, 1.0, 1.0) × 1.1 보정(텍스처가 회색 0.8대) |
| 속도 반응 | 알파 × smoothstep(0.15, 0.6, speed_normalized), 끝 폭 × lerp(0.6, 1.0, speed_normalized) | 같음 |
| 텍스처 | `weather_rain_wake_strip.png` | `weather_snow_wake_strip.png` |

- 그리는 순서: 트랙 → 타이어 자국 → **물보라 띠** → 차량(기존 월드 host 평면).
- 연결 끊기 규칙은 자국과 동일(발생 틈·피트·순간이동·거리 초과).
- 예상 부하: 20대 × 바퀴 2 × (수명/0.05s) ≈ 400~560 조각, MultiMesh 1개(자국과 별도 인스턴스 또는 같은 엔진의 두 번째 레이어). 월드 조각(draw call +75~85)을 없애므로 순감 기대.
- 폭 증가는 셰이더(인스턴스 custom data의 생성 시각)로 계산 → 매 프레임 CPU 갱신 없음.

## 5. Studio package 정리 (Claude)

- `driving.rain_tire_spray` / `driving.snow_tire_spray`에서 **월드 잔류 puff 레이어 제거**, 차 중앙 판(TEXTURED_SPRITE) **제거**(판 텍스처의 물줄기 시작점이 좁은 접점 기준으로 그려져 있어 넓은 접점에 맞출 수 없음).
- 남기는 것: **두 뒷바퀴 접점(±88, +155)에서 튀는 작은 파티클**(비: 빗방울, 눈: 눈 덩어리) — 좌·우 레이어, VEHICLE_LOCAL, 각 최대 2. 물보라 띠가 주 표현이 되고 파티클은 바퀴의 튐만 담당.
- START/END: 레이어 없는 phase 허용 여부를 Codex에 확인(불가하면 짧은 파티클 1회 BURST).
- `speed_normalized` 입력은 파티클이 modulation을 받지 않으므로 더 이상 필요 없음 → Runtime v1/v2 중 compiler 결과를 따름.
- 사용하지 않게 되는 Studio 리소스(`weather_*_rear_*`, `weather_*_puff`)는 package에서 빠지고, Studio 카탈로그 정리는 최종 승인 후.

## 7. 확정 사항 (Codex 회신 + 사용자 결정, 2026-09-30) — 2~5장보다 우선

- **사용자 결정**: 모든 차량 폭을 향후 가장 큰 차량과 비슷하게 맞추고 형태도 최종본이 아님 → **공통 접점 하나**, 차량별 override 없음. 기준 = 현재 가장 넓은 실제 바퀴(car_f): **(±102, +160), 타이어 폭 44 source px**. 2장의 차종별 표는 참고 기록으로만 남김.
- 자국: 폭 44 × 실제 CarSprite 배율 × 32/18, 슬립 1.2배 유지, 차량 배율 중복 금지, 반복 길이 ≈20(월드 거리).
- wake: 별도 관리 노드 + 비·눈 MultiMesh 2개, 자국 다음·차량 이전, 합산 용량 1,024, custom data = 생성 시각·UV 시작·UV 길이·생성 당시 속도, 수명·끝 폭·색은 재질 uniform, 발생은 `_update_visual_effects()` 조기 반환 앞 독립 타이머.
- package: Runtime **v1**, 좌·우 바퀴 파티클(CORE, offset ±102/+172)만, START 0.05s·END 0.3s 레이어 0개(양수 duration 필요, 회신 9).
- wake 텍스처 2장 검수 승인 → `exports/weather_wake_v1/`.
- 인계: [Codex 구현 인계](../../handoffs/2026-09-30-weather-wake-codex-handoff.md).

## 8. 1차 보정 (사용자 녹화 피드백, 2026-09-30) — 7장보다 우선

- 자국 진하기 차량별 편차: 속도 비례 `strength`(0.25~1.0)와 슬립 알파 1.5배 때문 → 하한 0.7, 슬립 1.2배.
- 공통 접점 ±102 → **±92**(자국·wake·package 파티클).
- wake: 시작 폭 타이어 폭 × 비 1.6 / 눈 2.0, 끝 × 4.0 / 4.5, 수명 0.30 / 0.28s(꼬리 직선 ≈60px), 알파 0.45 / 0.6.
- 눈 자국: 연회색 → 어두운 젖은 줄 (0.10, 0.11, 0.13) α0.30 — 흰 wake와 구분.
- 첫 눈 전환 31ms: wake·자국 재질 SETUP 준비 여부 확인 요청.
- 요청서: [Codex 보정 요청](../../handoffs/2026-09-30-weather-wake-tuning-codex.md). package 파티클 offset ±92로 재생성 완료.

## 9. 2차 보정 (2026-09-30) — 8장보다 우선

- 1차 적용 결과: 차량별 자국 편차 해소, 첫 눈 전환 31ms 재현 안 됨(원인 미확정).
- 접점 ±92 → **±84**(자국·wake·package 파티클). 눈 wake: 시작 ×1.7, 끝 ×3.6, 수명 **0.36s**(비 0.30s보다 약간 길게 — 눈이 가벼워 더 오래 날림), 알파 0.55. 이유: 폭 과함, 직선 밀집 시 회색 카펫.
- 요청서: [2차 보정](../../handoffs/2026-09-30-weather-wake-tuning2-codex.md). package 파티클 ±84로 재생성 완료.
