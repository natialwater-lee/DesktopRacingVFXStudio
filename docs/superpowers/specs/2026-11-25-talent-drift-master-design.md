## 1. 재능 사실 (게임 master 기준)

- 발동: 코너 추월 2회. 코너 구간이거나, 코너를 나온 지 1초 이내의 추월만 센다.
- 효과(12초): 코너 속도 ×1.15, 드리프트 손실 ×0.5, 재능을 가진 차 자신이 드리프트할 때의 추월·방어 불이익(±0.05) 제거.
- 종료: 12초 끝 / 레이서 교대 / 피트 진입.
- 컷인 강조색: 자홍 네온 (1.0, 0.24, 0.86).
- 측정(8트랙, 230주행):
  - 코너 구간이 주행 시간의 평균 약 82 %다.
  - 발동 중 12초 동안 드리프트는 평균 0.7회, 시간은 약 0.5초뿐이다(절반 가까이는 0회).
  - 따라서 **드리프트할 때만 보이는 연출로는 거의 보이지 않는다.**
- 이미 있는 드리프트 연출: 차 뒤쪽이 최대 13° 돌아가는 기울기(`_drift_visual_rotation_offset_deg`)와 진한 타이어 자국(코너·드리프트 중 뒷바퀴, alpha ×1.6, 폭 ×1.3).

## 2. 컷인 분석

| 시간 | 장면 |
|---|---|
| 0.0~0.75초 | 코너에서 옆으로 미끄러지는 차. 뒤로 **휘어진 자홍 네온 궤적 2~3가닥**이 노면에 길게 남는다. 분홍빛 타이어 연기가 피어나고, 바퀴 림이 자홍으로 빛난다. |
| 1.5~2.25초 | 상대 차 옆을 지나 추월한다. 뒷바퀴 뒤로 네온 궤적이 곧게 뻗고, 그 아래에 분홍 연기가 깔린다. |
| 3.0~4.0초 | 코너를 빠져나가는 차 뒤로 **코너 모양대로 휜 두 가닥 궤적**이 남고, 연기는 옅어진다. |

참고 캡처(GPT 첨부용):
- 위치: 공용 노트 폴더 `drift_master_ref/`
- 파일: `0.75s_trails_smoke`, `2.25s_trail_behind`, `3.75s_curved_trails`

### 가져올 요소
1. **휘어진 자홍 네온 궤적(여러 가닥)** — 재능의 핵심. 코너를 그리며 미끄러진 자리.
2. **분홍빛 타이어 연기** — 드리프트 순간의 강조.

### 뺄 / 바꿀 요소
- **원형 자홍 바퀴 림 빛 → 뺀다** (지훈 11-25 결정). 리바운드가 뒷바퀴 민트 림 빛을 쓰고 있어, 형태가 겹친다.
- **노면에 남는 궤적(월드 잔류) → 차에 붙은 꼬리로 바꾼다.**
  - 기존 타이어 자국이 이미 노면에 남으므로 그 역할과 겹치지 않게 한다.
  - 월드 잔류 입자는 8대일 때 비용이 크다.
  - 대신 `visual_bend`로 꼬리를 **지나온 코너 궤적을 따라** 휘게 해서, 남은 궤적처럼 읽히게 한다.
- 상대 차, 배경 도시, 카메라 움직임, 화면 전체 효과는 쓰지 않는다.

### 기존 VFX와 구분
| 기존 | 드리프트 마스터와 차이 |
|---|---|
| 리바운드: 민트 뒷바퀴 캡슐 림 + **차 양옆(±140) 직선 고정 레일**(앞바퀴 앞~차 뒤) | 자홍. 림 없음. **뒷바퀴 뒤에서 시작해 뒤로만** 뻗고, 코너에서 휘는 꼬리 |
| 슈퍼부스터: 차 중앙 뒤의 휘는 불꽃 꼬리 | 중앙이 아니라 **좌우 뒷바퀴 2줄**. 불꽃이 아닌 네온 광선 |
| 다운포스 윙: 흰 바람선이 날개 끝(±300)에서 흔들림 | 자홍 네온. 뒷바퀴 위치. 좌우 흔들림이 아니라 궤적 모양 휨 |
| 레인 서퍼 / 스노우 보더: 노면에 남는 물·눈 궤적 | 노면에 남기지 않음 |
| 독주: 금빛 고정 리본이 뒤로 흐름 | 흐르지 않음. 자홍, 코너 형태 |

## 3. 연출 (시작 · 유지 · 드리프트 순간 · 종료)

상시 연출(LOOP)이 재능을 보여 주는 주 역할을 맡는다. 드리프트 순간 강조는 그 위에 더하는 보너스다.

### 시작 START — 약 0.6초 ("코너를 지배하기 시작")
- **꼬리 그어짐**: 좌우 네온 꼬리가 뒷바퀴 뒤에서부터 0.35초 만에 그어진다(길이 0→1.15, 이후 1.0으로 정착). 밝기는 최대에서 시작한다.
- **분홍 연기 터짐**: 뒷바퀴마다 BURST 3개(총 6). 뒤쪽 바깥 방향으로 퍼지며 0.6초에 사라진다. ALPHA.
- **바닥 번쩍임**: 차 밑에 자홍 빛 웅덩이(헤이즈 텍스처)가 0.15초 만에 켜졌다가 0.45초에 걸쳐 유지 밝기로 내려간다. UNDER_VEHICLE.

### 유지 LOOP — 12초 ("코너를 그리며 달린다")
- **네온 꼬리 ×2** (좌우):
  - 위치는 뒷바퀴 바로 뒤, 조금 바깥쪽이다. 머리 (±95, +205) source px에서 뒤로 약 640 source px 뻗는다.
  - 화면 x1에서 폭 약 6px, 길이 약 60px(차 길이 약 1.2배)다.
  - 한 장 안에 **2가닥 평행 광선**(흰빛 심 + 자홍 번짐)이 들어 있어, 얇은 선 하나가 아닌 두께와 결이 있다. ADDITIVE.
- **꼬리 헤이즈 ×2**: 꼬리 아래에 깔리는 넓고 부드러운 분홍·자홍 빛 층이다(폭 약 1.6배, alpha 약 0.5). 입체감과 노면 반사 느낌을 준다. ADDITIVE.
- **코너 휨**: 꼬리·헤이즈 4개 모두 `visual_bend`(QUADRATIC, 머리 고정)를 쓴다.
  - 입력은 `turn_rate_normalized`이고, 실사용 범위 ±0.2를 꽉 채워 매핑한다(다운포스 교훈).
  - 오른쪽 코너(+)에서는 꼬리 끝이 +x(안쪽)로 간다. **지나온 궤적이 휘는 방향**과 같다. 목표 끝 이동은 화면 약 8px(≈85 source px)이다.
  - 코너가 주행의 82 %라 거의 늘 휜 궤적으로 보인다.
- **코너 세기 연동**: |turn_rate|가 클수록 꼬리 길이 ×1.0→1.15, 밝기 ×0.85→1.0. 직선에서는 곧고 조금 짧고 차분하다.
- **숨쉬기 없음**: 리바운드의 0.8 Hz 숨쉬기와 구분한다. 밝기 변화는 코너·드리프트에만 반응한다.
- 매 프레임 생성하는 입자는 없다.

### 드리프트 순간 — 새 입력 `drift_active` (지훈 11-25 결정)
- 입력: `drift_active` (0~1). Game이 `CarAgent.is_race_ability_drift_active()`에서 공급하고, **켜질 때 약 0.05초, 꺼질 때 약 0.4초**로 보간한다(`boost_active`와 같은 방식). 드리프트 약 0.5초 + 여운 0.4초로 약 0.9초 보인다.
- 반응:
  - 꼬리: 밝기 ×1.5, 길이 ×1.35, 폭 ×1.2.
  - 헤이즈: 밝기 ×1.8.
- **분홍 드리프트 연기 ×2**: 뒷바퀴 뒤에 TEXTURED_SPRITE 연기 덩어리를 둔다. opacity 0→0.85, 크기 0.8→1.2로 피어난다. ALPHA. 평소에는 opacity 0이다.
  - 선택(②에서 판단): `turn_rate`로 연기를 바깥쪽으로 조금 밀어(TRANSFORM_OFFSET_X ADD) 미끄러지는 방향을 강조한다.
- 기존 드리프트 기울기·타이어 자국은 그대로 둔다.
  - 자국은 노면에 남는 어두운 선이다. 이 VFX는 차에 붙은 빛이고 자국보다 뒤로 길다.
  - 드리프트 순간에도 노면에 새로 남기는 것은 없다.

### 종료 END — 약 0.4초
- 꼬리·헤이즈가 머리 쪽으로 줄어들며 사라진다.
- 리바운드 교훈: END에서는 TEXTURED_SPRITE에 시간 램프를 걸 수 없다. 그래서 PARTICLE 복사본 페이드나 LOOP 끝 처리로 구현한다(②에서 확인).
- 레이서 교대·피트 진입은 게임의 강제 정리(force_clear)로 즉시 제거한다.

- 확인 필요:

  - opacity 0인 연기 스프라이트의 그리기 비용도 ③ 부하 측정에서 본다. 필요하면 visible 끄기를 Game에 요청한다.

## 5. 기존 기능으로 가능한지 / 계약 변경

- 기존 기능으로 가능한 것(모두 Runtime 2, 게임 지원 확인됨):
  - TEXTURED_SPRITE + `visual_bend` + `VISUAL_BEND_OFFSET_X`
  - `turn_rate_normalized` LINEAR_RANGE (슈퍼부스터·다운포스)
  - opacity·scale 모듈레이션
  - PARTICLE BURST, UNDER_VEHICLE
- **계약 변경 1건: 새 runtime 입력 `drift_active`** (0~1, 기본 0, `boost_active`와 같은 부호 없는 스칼라).
  - Studio(②): 스키마 `x_vfx_runtime_inputs`에 추가하고, 문서(`VFX_SCHEMA_V1.md`, `VFX_STUDIO_ARCHITECTURE.md`)를 고친다. preview에 Drift 슬라이더와 램프 토글(0.05/0.4초)을 둔다.
  - Game(③):
    - `VfxEffectInstance._resolve_runtime_input_snapshot_slots`에 `drift_active` 슬롯과 보간을 추가한다.
    - `VfxService.validate_vehicle_runtime_inputs`에 공급자 검사(`CarAgent`가 `is_race_ability_drift_active`를 갖는지)를 추가한다.
    - 공급 값은 `is_race_ability_drift_active()`다.
    - 기능 세션이 이미 만든 `drift_state_changed` 신호나 `get_drift_visual_state()`를 써도 되지만, 매 프레임 스냅샷 방식이면 함수 하나로 충분하다.
  - 미지원 Game에서는 이 package를 명시적으로 거부해야 한다(조용히 0으로 대체 금지 — 기존 규칙).
- Studio preview는 `visual_bend`를 그리지 않는다(슈퍼부스터 기록). 휨은 Game 캡처로 확인한다.
- ③ 확인 사항:
  - 드리프트 기울기(최대 13°) 중에 VEHICLE_LOCAL 효과가 차 스프라이트 회전을 따라가는지 본다. 따라가면 꼬리도 함께 돌고, 안 따라가도 궤적 느낌상 문제없음.
  - 타이어 자국과 겹친 모습을 확인한다.
  - 8대 동시 부하를 측정한다.
