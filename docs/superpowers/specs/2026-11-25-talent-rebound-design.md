## 1. 재능 사실 (기획서 확정)

- 발동: 큰 미끄러짐 1회. 발동 순간 차는 **옆으로 크게 밀리며 회전 중**(약 2.5초, 끝 38 %가 회복 단계).
- 효과: 타이어 마모 ×0.5 (20초), 발동시킨 큰 미끄러짐의 남은 회복 단계 즉시 종료. 차선 복귀 움직임은 그대로.
- 종료: 20초 끝 / 레이서 교대 / 피트 진입.
- 의미: **미끄러졌다가 곧바로 접지를 되찾고, 이후 타이어를 아끼며 안정적으로 달린다.**

## 2. 컷인 분석

| 시간 | 장면 |
|---|---|
| 0.0~0.75초 | 옆으로 미끄러지며 검은 타이어 연기. 바퀴 빛 꺼짐 |
| 1.0초 | **네 바퀴 림에 민트·청록 빛 고리 점화**, 접지면에 청록 안개. 배기 주황 불꽃 |
| 1.25~2.5초 | 연기 걷히고 차체 정렬, 림 빛 유지 |
| 2.5~4.0초 | **노면에 평행한 얇은 민트 라인 2줄**이 차 앞뒤로 길게 뻗음, 림 빛 유지 |

### 가져올 요소
1. **민트 림 빛** — 재능의 핵심. 회전 잔상 없이 **차분하고 고른 빛**(돌지 않음).
2. **접지면 청록 안개** — 점화 순간 바퀴가 노면을 다시 붙잡는 느낌.
3. **노면의 평행 민트 라인 2줄** — 궤도를 되찾은 안정감.

### 뺄 / 바꿀 요소
- 검은 타이어 연기: 슬립 자체 연출이고, 무겁고 트랙을 가림 → 뺌(게임은 차량 밀림·회전으로 이미 슬립을 보여 줌).
- 배기 주황 불꽃: 기본 부스터와 혼동 → 뺌.
- 앞바퀴: 차종마다 위치가 달라 **뒷바퀴 공용 위치 (±84, +160) source px에만** 둠.
- 측면 시점의 원형 림 → 탑뷰에서 바퀴는 **세로로 긴 직사각형**이므로 원형 고리 대신 **바퀴 윤곽을 감싸는 캡슐형 빛 테두리**로 재구성.
- 카메라·배경·화면 전체 효과 없음.

### 기존 VFX와 구분
| 기존 | 리바운드와 차이 |
|---|---|
| 피트스톱 에이스: 주황+파랑 **원형 고리가 빠르게 회전**, 청록 출발 라인이 **뒤로 흘러감**(5.5초) | 민트 **캡슐형 테두리, 회전 없음**, 라인은 **흐르지 않고 차 앞뒤로 고정** |
| 레인 서퍼 / 스노우 보더: 뒷바퀴에서 노면에 **남는 궤적**(파랑 / 흰빛) | 노면에 남기지 않음. 차에 붙은 **고정 가이드 레일** |
| 타이어 배리어: 차 전체를 감싸는 청색 원형 필드 | 바퀴 국소 + 얇은 두 줄 |

## 3. 연출 제안 (시작 · 유지 · 종료)

### 시작 START — 약 0.9초 ("다시 붙잡는다")
- **림 점화**: 뒷바퀴 2곳 캡슐 테두리가 크기 ×1.6·최대 밝기로 번쩍인 뒤 0.3초에 걸쳐 유지 상태 크기·밝기로 가라앉음. OVER_VEHICLE(뒷바퀴가 차체 가장자리 아래라 위에 그려야 보임 — 피트스톱 에이스 교훈).
- **접지 안개**: 뒷바퀴마다 민트 안개 1~2개가 퍼지며 0.6초에 사라짐(UNDER_VEHICLE).
- **레일 스냅**: 양옆 가이드 레일이 뒤→앞으로 0.35초 만에 그어짐(길이 0→1).
- 발동 순간 차가 미끄러지는 중이므로 효과는 차에 붙어 같이 움직인다.

### 유지 LOOP — 20초 ("타이어를 아끼며 안정 주행")
- **림 빛**: 뒷바퀴 캡슐 테두리, 알파 0.55~0.85를 약 0.8 Hz로 느리게 숨쉬듯.
- **가이드 레일 2줄**: 차 양옆 바깥(x ±140 부근), 앞바퀴 앞~차 뒤까지(차 길이 약 1.5배) 얇게 고정. 알파 약 0.45, 림 빛과 같은 박자로 미세하게 밝기 변화. UNDER_VEHICLE.
- 지속 생성 파티클 없음. 지속 구간은 **TEXTURED_SPRITE 4개**뿐.

### 종료 END — 약 0.4초
- 레일이 앞→뒤로 줄어들며 사라지고 림 빛 페이드.
- 레이서 교대·피트 진입은 게임의 강제 정리(force_clear)로 즉시 제거.

### 화면 크기 기준 (x1, 차 약 24×49px)
- 림 테두리 약 7×11px, 선 굵기 2px 이상.
- 레일 약 2~3px × 70px.
- 접지 안개 약 14×14px.

## 4. 부하

- START: 버스트 파티클 2~4개 + 스프라이트 4개(0.9초).
- LOOP: 스프라이트 4개, 매 프레임 생성 없음 → 5~8대 동시라도 기존 재능(스노우 보더 6대 +0.4 ms)보다 가벼울 것으로 예상. 실제 측정은 ③단계에서.

## 5. 기존 기능으로 가능한지

- TEXTURED_SPRITE + OSCILLATOR(opacity) + LINEAR_PHASE(START 크기·길이) + PARTICLE BURST, OVER_VEHICLE / UNDER_VEHICLE — 모두 Runtime 2에서 게임 지원 확인된 기능(엔지니어·피트스톱 에이스·절대 방어). **계약 변경·새 runtime 입력 없음.**
- ③단계 확인 사항: 큰 미끄러짐 중 차량 시각 오프셋·회전(`_big_slip_visual_offset`, `_big_slip_visual_rotation_offset_deg`)을 VEHICLE_LOCAL 효과가 따라가는지.
- 선택(권장 안 함): "회복 단계가 잘리는 순간"에 맞춘 두 번째 번쩍임은 게임 신호가 새로 필요 → 이번에는 발동 순간 START만 사용.
