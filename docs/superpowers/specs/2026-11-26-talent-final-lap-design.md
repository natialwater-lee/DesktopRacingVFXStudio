## 1. 재능 사실

- 조건: 마지막 랩 동안 앞 순위 차와의 시간 간격이 처음 1.5초 이내가 되는 순간. 1위 제외. 주행당 성공 1회 규칙 그대로.
- 효과(20초): 발동 순간 부스트 게이지 즉시 가득(1회) + 최고속 ×1.05 + 가속 ×1.1.
- 종료: 지속 끝 / 완주. 마지막 랩은 피트 진입이 막혀 레이서 교대·피트 종료는 사실상 없다.
- 레이스 랩 5~30 → 마지막 랩은 레이스의 3~20 %. 발동하면 결승까지 이어지는 경우가 많다 → **END보다 결승선 통과로 끝나는 경우가 많다.**

### 부스트 게이지가 차면 실제로 일어나는 일 (게임 코드)
- 게이지를 채워도 **그 자리에서 부스트가 켜지지 않는다.** 부스트는 사용 타이머(4~12초 간격)가 끝났을 때 게이지 ≥ 50이면 1.5~3초 켜진다(초당 25 소모). 이미 부스트 중이면 그 부스트가 게이지 0이 되기 전에 지속 시간 끝으로 꺼진다.
- 그래서 20초 동안 일반 부스트가 보통 **2~3번** 켜진다. 일반 부스터 VFX(뒤쪽 노즐 4개의 주황·노랑 분사, UNDER)가 파이널 랩 효과와 **자주 같이 보인다.**
- 슈퍼 부스터(특수장비) 작동 중에는 일반 부스터가 숨겨지고 `boost_active`도 0이다.

## 2. 컷인 분석

| 시간 | 장면 |
|---|---|
| 0.0~0.8초 | 은색 내 차의 **양옆을 따라 빛나는 흑백 체커 리본**이 노면 위에서 물결치며 뒤로 흐른다. 리본은 앞차(붉은 차)와 그 너머 **빛나는 흰 결승 게이트**까지 이어진다. 진홍 노을 하늘. |
| 1.2초 | 체커 물결이 노면 전체로 번지며 차 뒤에서 큰 체커 판이 밀려온다. |
| 1.6초 | 체커가 차체로 흡수되어 **차체 전체가 흰빛으로 빛나고**, 배기구에서 주황 불꽃이 터진다(게이지 충전 → 가속). |
| 2.4~4.0초 | 체커가 사라지고 앞차를 쫓아 결승 게이트로 달린다. 게이트가 크게 다가온다. |

### 가져올 요소
1. **물결치는 흑백 체커 리본** — 재능의 상징. 차 양옆을 따라 뒤로 펄럭인다.
2. **흰 결승선(게이트) 빛** — "마지막 바퀴, 결승이 눈앞"이라는 의미. 시작 순간에 쓴다.
3. **체커가 차로 흡수되며 충전** — 게이지가 한 번에 가득 차는 순간.
4. **진홍** — 하늘·노을의 색. 리본 아래 노면 반사와 가장자리 빛으로만 쓴다.

### 뺄 / 바꿀 요소
- 배기 주황 불꽃 → 넣지 않는다. 실제 부스트가 켜지면 **일반 부스터 VFX가 그 역할을 한다**(겹치지 않게 뒤 중앙은 비운다, 3-4).
- 차체 전체 흰 발광 → 차종마다 모양이 달라 차체에 맞출 수 없다. 시작 순간 차 중심 섬광으로 줄인다.
- 노면 전체 체커 판·결승 게이트 구조물·앞차까지 이어지는 리본 → 탑뷰 작은 화면에서 트랙·다른 차를 가린다. 결승선은 **차 밑을 지나가는 체커 띠 1개**로 바꾼다. 리본은 내 차 옆과 뒤에만.
- 카메라·노을 하늘 → 뺀다.

### 기존 VFX와 구분
| 기존 | 파이널 랩과 차이 |
|---|---|
| 리바운드: 민트 림 + 양옆 **곧은 빛 레일** | 빛 레일이 아니라 **흑백 무늬가 있는 천 리본**, 물결친다. 민트 없음. |
| 드리프트 마스터: 자홍 꼬리, 코너에서 휨 | 꼬리 1개가 아니라 양옆 리본 2개, 흑백 + 진홍. |
| 체인 바인드: 강철 사슬 + 쇳물 주황 | 금속·사슬 없음, 다른 차에 아무것도 안 붙임. |
| 휠투휠: 양옆 흰 공기 압력 반달 + 노란 불꽃 | 양옆이지만 **체커 무늬 천**이 뒤로 길게 흐른다. 반달·불꽃 없음. 노랑 없음. |
| 독주: **금빛** 고정 리본이 뒤로 흐름 | 리본이지만 **흑백 체커 무늬**(색 없음) + 진홍 반사. 금빛 없음. 차 양옆 바깥에 있고 차체 위에는 없다. |
| 분노의 추월: **진홍 전기 균열** + 스파크 | 진홍은 노면 반사·가장자리 빛뿐. 전기·스파크 없음. |
| 하위권의 반란: 적주황 불꽃 줄기가 뒤→앞 | 불꽃 없음, 흐름 방향은 앞→뒤. |
| 피트스톱 에이스: 청록 출발 라인이 뒤로 흐름 | 시작 순간 결승선 띠는 **체커 무늬**이고 1회뿐. |
| 일반 부스터: 뒤 중앙 주황·노랑 분사 / 슈퍼 부스터: 청록·파랑 분사 | 뒤 중앙은 비운다. 흑백 + 진홍이라 색이 겹치지 않는다. |

## 3. 연출

### 역할 분담
| 구간 | 무엇 | 의미 |
|---|---|---|
| 시작 START ≈0.7초 | 진홍 **충전 고리가 차로 빨려 들어가고** 흰 섬광 → **체커 결승선 띠가 앞코에서 뒤로 차 밑을 지나감** → 양옆 리본이 앞에서 뒤로 **휙 펼쳐짐** | "게이지가 한 번에 가득 찼다 / 마지막 바퀴, 결승선을 향해" |
| 유지 LOOP | 양옆 **흑백 체커 리본**이 펄럭이며 뒤로 흐름 + 리본 아래 **진홍 노면 반사** | "이 차는 지금 마지막 추격 중" |
| 부스트 중(유지 안) | 리본이 뒤로 **더 길게 뻗고** 진홍 반사·가장자리 빛이 강해짐 (`boost_active`) | 채운 게이지로 실제 가속하는 순간을 일반 부스트와 함께 강조 |
| 종료 END ≈0.4초 | 리본이 뒤에서 앞으로 말려 들어가며 사라짐 | — |

### 3-1. 유지 LOOP 레이어 (`talent.final_lap`)

| 레이어 | 합성·평면 | 역할 |
|---|---|---|
| `flag.spill` | ADDITIVE, UNDER | 리본 아래 노면의 **진홍 반사**. 리본이 노면 위에 떠 있게 하는 입체감 + 진홍 정체성. |
| `flag.body` | ALPHA, UNDER | 양옆 체커 리본 본체. **흑백 사각형 2줄**, 천이 접힌 곳마다 밝은 면·그늘진 면이 있어 **두께와 굴곡**이 보인다. 흰 칸은 어두운 트랙에서, 검은 칸은 밝은 트랙에서 보이므로 어느 트랙에서나 읽힌다. |
| `flag.sheen` | ADDITIVE, UNDER | 같은 리본 위의 **흰 광택(접힌 마루) + 바깥 가장자리 진홍 빛**. 리본이 빛을 받는 천처럼 보이게. |

- 크기(화면, 차 약 24×49px 기준): 리본 하나는 차 앞 어깨 옆에서 시작해 차 뒤끝을 지나 **차 길이 약 0.45배 뒤**까지, 길이 약 65px, 폭 약 7~8px(체커 한 칸 약 3.8px, 2줄). 차체에서 약 3px 띄우고, 뒤로 갈수록 바깥으로 조금 벌어진다. 좌우 한 장에 같이 그린다(그리기 수 절반).
- 리본은 차 밑(UNDER)에 둔다. 앞쪽 끝은 차 옆구리 밖이라 가려지지 않는다.
- **펄럭임**: 기존 `visual_bend`(드리프트 마스터에서 Game 지원 완료)의 `VISUAL_BEND_OFFSET_X`에 OSCILLATOR 2개(약 1.3Hz + 2.1Hz, 작은 진폭)를 더해 리본 꼬리가 좌우로 흔들린다. 코너에서는 `turn_rate_normalized`(±0.2 꽉 채움)를 더해 꼬리가 바깥으로 휜다.
- **흐름**: 체커 무늬가 뒤로 흐르는 느낌은 `TRANSFORM_OFFSET_Y` 톱니(LINEAR_PHASE, 체커 2칸 주기)로 낸다. 리본 양 끝의 흐려지는 부분이 함께 밀려 이음매가 보이는지 ②에서 확인하고, 보이면 흐름은 빼고 펄럭임만 둔다.
- 숨쉬기 없음. 밝기 변화는 부스트 상태에서만 나온다.

### 3-2. 부스트 연동 — 기존 입력 `boost_active` (에너지 전환·엔지니어가 이미 사용, Game 공급 완료)
- 평상시(0): 리본 본체 0.85, 광택 0.55, 반사 0.35.
- 부스트 중(1): 리본 길이 ×1.25(앞쪽 끝 고정, 뒤로 늘어남), 광택 1.0, 반사 0.8, 펄럭임 진폭 ×1.4.
- 부스트가 끝나면 0.3초에 걸쳐 돌아온다(Game 기존 평활: 올림 0.08초 / 내림 0.3초).
- 슈퍼 부스터 작동 중에는 `boost_active` = 0 → 리본은 평상시 모습. 슈퍼 부스터 분사(뒤 중앙)와 리본(양옆)은 자리가 달라 겹치지 않는다.

### 3-3. 시작 START ≈0.7초
| 시간 | 레이어 | 동작 |
|---|---|---|
| 0.00~0.30 | `start.charge_ring` ADDITIVE, OVER | **진홍-흰 고리**가 차 크기의 약 2배에서 **차 중심으로 줄어들며**(배율 2.0→0.5) 밝아진다. "게이지가 빨려 들어가 가득 참". |
| 0.25~0.45 | `start.charge_flash` ADDITIVE, OVER | 고리가 닿는 순간 차 중심 **흰 섬광 + 진홍 빛살**(0.2초). |
| 0.25~0.65 | `start.finish_line` ALPHA, UNDER | 차 폭의 약 1.8배인 **체커 결승선 띠(흰 빛 번짐 포함)**가 앞코 앞에서 차 밑을 지나 뒤끝 뒤까지 이동하며 사라진다. 차가 결승선을 막 통과하는 모습. |
| 0.30~0.70 | LOOP 리본·반사 | 리본이 앞쪽 끝을 고정한 채 길이 ×0.2→1.1→1.0로 **뒤로 휙 펼쳐진다**. 반사도 같이 켜진다. START 중 같은 레이어를 CONTINUOUS로 미리 만들어 LOOP로 넘어갈 때 비는 프레임을 없앤다(샌드위치 탈출 교훈). |

- 발동 순간에 이미 부스트 중이면 리본은 바로 부스트 모습(×1.25)으로 펼쳐진다.

### 3-4. 일반·슈퍼 부스터와 겹침
- **뒤 중앙 비움**: 일반 부스터 분사는 노즐 x ±22/±66 source px, 뒤끝 뒤 약 15px. 리본 꼬리는 그보다 바깥(차 중심에서 화면 약 ±15px 이상)에 둬 분사를 가리지 않는다. 결승선 띠는 START 0.4초만 지나간다.
- **색 분리**: 부스터 = 주황·노랑(일반) / 청록·파랑(슈퍼). 파이널 랩 = 흑백 + 진홍. 노랑·주황을 쓰지 않는다.
- **역할 분리**: 부스트 자체의 불꽃은 부스터 VFX가, "파이널 랩 부스트"라는 표시는 리본이 늘어나는 것으로 한다. 부스터 VFX는 고치지 않는다.
- 같이 켜졌을 때 그리기 순서: 반사 → 리본 → 광택 → (부스터 분사) → 차. 실제 순서는 ③에서 확인한다.

### 3-5. 종료 END ≈0.4초
- 리본이 뒤에서 앞으로 말려 들어가며(길이 1.0→0.2) 사라지고 반사도 꺼진다. TEXTURED_SPRITE는 END에서 시간 램프가 안 되므로 PARTICLE 복사본 페이드로 만든다(리바운드·드리프트 마스터와 같은 방법). PARTICLE 복사본은 휘지 않으므로 코너에서 끝나면 펴지며 사라진다.
- 완주로 끝날 때도 같은 END. 결승선 연출을 따로 두지 않는다(게임 결승 연출과 겹침 방지).

## 4. 부하 (8대 동시 발동 기준)

| 구간 | 1대 | 8대 |
|---|---|---|
| LOOP | 스프라이트 3, 입자 0 | **24 그리기** |
| START | 스프라이트 3 + 고리 1 + 섬광 1 + 결승선 1 | 48 |
| END | 입자 3 | 입자 24 |

- 휠투휠 LOOP(24)과 같고 리바운드(10/대)보다 가볍다. 지속 생성 입자 없음.
- 8대 동시 발동은 실제로는 드물다(마지막 랩, 1위 제외, 칸 경쟁). 그래도 ③에서 8대 강제 발동으로 측정한다. 무거우면 광택 → 반사 순으로 뺀다.

## 5. 새 기능 범위

- **새 기능·새 runtime 입력 없음.** 모두 Game 지원이 끝난 기능이다.
  - TEXTURED_SPRITE + `visual_bend`/`VISUAL_BEND_OFFSET_X`(드리프트 마스터), OSCILLATOR, LINEAR_PHASE, `TRANSFORM_OFFSET_Y` ADD(엔지니어), PARTICLE BURST
  - 입력 `boost_active`(에너지 전환), `turn_rate_normalized`(슈퍼 부스터·다운포스·드리프트 마스터)
- ②에서 확인할 것: OSCILLATOR가 `VISUAL_BEND_OFFSET_X`를 움직이는 조합(드리프트 마스터는 turn만 썼다)이 Studio preview와 Game evaluator에서 같은지. 다르면 흐름·펄럭임을 TRANSFORM_OFFSET_X 흔들기로 대신한다.
- Runtime Definition v2 예정.

## 6. 기능 세션(게임) 쪽

- **VFX를 위한 추가 작업 요청 없음.** 게이지가 채워지는 순간은 발동 순간과 같은 틱이므로 START가 그대로 맡는다. 앞차 간격은 연출에 쓰지 않는다(6-1 참고).
- 확인만 부탁:
  1. 완주로 끝날 때도 다른 재능과 같은 종료 경로(`on_ability_ended`)를 타는지. 결승 후 바로 사라져도 되는지(END 0.4초만 재생).

- 측정 때 함께 받을 값: 발동 시점(랩 진행률·결승까지 남은 시간), 20초 안의 일반 부스트 횟수·총 시간, 완주로 끝난 비율.

### 6-1. (참고) 앞차 간격을 연출에 쓸까? → **쓰지 않는다(권장)**
1. 발동 뒤 앞차가 바뀌거나(추월) 1위가 되면 기준이 사라져 값이 튄다.
