## 1. 재능 사실 (게임 코드에서 확인)

- 조건: 다른 차와 나란히 달린 시간 누적 4초(상대 무관 합산). 지속 12초. 종료: 지속 끝 / 레이서 교대 / 피트 진입.
- 효과 ①: 내가 뒤차일 때 배틀 시작 거리 40 → 60, 배틀 종료 거리 60 → 90.
- 효과 ②: 배틀 홀드 면역. 앞차가 막아도 속도가 묶이지 않고 **앞차 옆 빈 차선으로 차선 변경**한다(장비 슈퍼 부스터·다운포스 윙과 같은 경로, 장비 배율·손실 없음). 빈 차선이 없으면 그냥 따라간다(이때도 `hold_resisted`는 나온다).

### VFX 입력이 나오는 정확한 순간
| 신호 | 언제 | 그때 상대와의 거리 |
|---|---|---|
| `wheel_to_wheel_event(car, "battle_start", front)` | **거리 40을 넘는 앞차와 배틀이 시작될 때만**(재능의 늘어난 사거리 덕분에 시작된 배틀). 40 이내 배틀은 신호가 없다. | 40~60(차 길이 약 48의 0.8~1.25배 앞) |
| `wheel_to_wheel_event(car, "hold_resisted", front)` | 배틀 판정에서 막혔는데 홀드 대신 옆으로 빠질 때. 판정은 배틀 시작 즉시 1회, 이후 차선 이동 시간(약 0.3~1초) 또는 1초마다. | 0~60. **배틀 시작과 같은 틱에 같이 나올 수 있다.** |
| `get_wheel_to_wheel_visual_state()` | 매 프레임 읽기. `active`, `in_battle`, `battle_target`, `side_by_side`, 횟수 2개 | — |

- 실제 발생 빈도(발동 1회당 몇 번)는 기능 세션 측정(남은 일 1번)에서 나온다. ②에서 강도·최소 간격을 그 값으로 확정한다.

## 2. 컷인 분석

| 시간 | 장면 |
|---|---|
| 0.0~0.4초 | 은색 내 차와 청록 상대 차가 **바짝 나란히**. 두 차 위로 **흰 공기 압력 반달(호)**이 여러 겹 겹쳐 휘고, 두 차 사이 낮은 곳에서 노란 불티가 튄다. 뒤로 흰 속도선. |
| 0.8초 | 내 앞 오른쪽 모서리와 상대 뒤 왼쪽 사이에서 **노랑-흰 불꽃 분수**가 크게 터진다(부채꼴, 위·뒤로). 차 밑 주황 빛. |
| 1.2~2.0초 | 흰 압력 호가 두 차를 덮으며 연기처럼 번지고, 내가 반 차 길이 앞선다. |
| 2.8~3.6초 | 내가 완전히 앞서고 상대는 흰 연기 속에 뒤처진다. |

### 가져올 요소
1. **흰 압력 반달** — 차 양옆을 감싸 휘는 굵은 공기 압력 호. 재능의 상시 표식.
2. **노랑-흰 불꽃 분수** — 차와 차가 부딪쳐 비비는 순간. 막혔는데 버틴 순간의 표식.
3. **앞으로 들이미는 압력** — 배틀을 거는 순간.

### 뺄 / 바꿀 요소
- 상대 차에 붙는 연출 → 넣지 않는다(3-4 참고).
- 계속 튀는 불티·흰 연기 → 지속 입자는 8대 부하가 커서 뺀다. 불꽃은 순간 연출에만.
- 차 밑 주황 빛 → 노란 **노면 반사 띠**(압력 호 아래)로 바꾼다. 주황은 체인 바인드 색이라 쓰지 않는다.
- 카메라·여러 겹 호 → 차 양옆 호 한 쌍으로 줄인다.

### 기존 VFX와 구분
| 기존 | 휠투휠과 차이 |
|---|---|
| 리바운드: 민트 림 + 양옆 **곧은 레일** | 양옆이지만 **바깥으로 휜 반달 압력 호**, 흰색 + 노란 테. 직선·민트 없음. |
| 드리프트 마스터: 자홍 꼬리, 뒤로 뻗음 | 뒤 꼬리 없음. 앞 어깨에 무게가 있는 호. |
| 체인 바인드: 강철 사슬 + 쇳물 주황, 대상 뒷범퍼 족쇄 | 금속 물체 없음, 상대 차에 아무것도 안 붙임. 불꽃은 **레몬 노랑-흰빛**(주황 아님). |
| 샌드위치 탈출: 금색 화살표가 앞으로 / 독주: 금색 리본 | 금색 기호·리본이 아니라 **공기 압력과 마찰 불꽃**. 화살표 없음. |
| 분노의 추월: 진홍 전기 + 스파크 | 전기 없음, 불꽃은 노랑. |
| 절대 방어: 옆 반투명 에너지 막 + 뒤 U | 에너지 막이 아니라 흰 **공기** 압력. 뒤 방패 없음. 배틀 중 앞으로 기울어짐. |

## 3. 연출

### 역할 분담
| | 무엇 | 의미 |
|---|---|---|
| 상시 LOOP `talent.wheel_to_wheel` | 차 양옆 **흰 압력 반달 + 노란 테 + 노면 반사** | "이 차는 지금 몸싸움에서 밀리지 않는다". 배틀 중에는 더 진하고 앞으로 기운다. |
| 순간 ① 배틀 시작 `…_surge` | 앞코에서 **앞으로 튀어 나가는 흰 압력파** + 앞 모서리 불티 | "먼 앞차에도 덤빈다"(늘어난 사거리) |
| 순간 ② 막혔는데 버팀 `…_grind_*` | 상대 쪽 앞 모서리 **노랑-흰 불꽃 분수 + 섬광**, 반대쪽으로 **흰 압력 반달이 차고 나감** | "막혔지만 비비고 옆으로 빠져나간다"(홀드 면역) |

### 3-1. 재능 차 `talent.wheel_to_wheel` (12초)

| 레이어 | 합성·평면 | 역할 |
|---|---|---|
| `flank.spill` | ADDITIVE, UNDER | 압력 호 아래 노면에 비친 **노란 반사 띠**. 호 테 그림을 흐리게 만든 것(②에서 처리). 입체감: 호가 노면 위에 떠 있게. |
| `flank.body` | ALPHA, OVER | 양옆 압력 호 본체. **흰~연회색 공기 덩어리**, 안쪽 어두운 음영으로 두께. 밝은 트랙에서도 보이게 ALPHA. |
| `flank.edge` | ADDITIVE, OVER | 같은 호의 바깥 테. **흰 심 + 레몬 노랑 빛**. |

- 크기(화면, 차 약 24×49px 기준): 호 하나 길이 약 55px(차 길이 1.1배), 앞 어깨 두께 약 8px → 꼬리 약 3px, 차체에서 약 3px 띄움. 테 약 2px. 좌우 한 장에 같이 그린다(그리기 수 절반).
- **시작 START ≈0.5초**: 호가 차체에서 바깥으로 튀어나오듯 펼쳐짐(배율 0.7→1.15→1.0), 테 ×1.6 번쩍 → 0.3초에 정착. 압력파 1회(surge와 같은 그림, 작게)로 "발동"을 알린다.
- **유지 LOOP** — 새 입력 `battle_engaged`(0~1)에 반응:
  - 평상시(0): 호 본체 0.55, 테 0.6, 반사 0.3. 숨쉬기 없음 — 변화는 실제 배틀 상태에서만 나온다.
  - 배틀 중(1): 호 본체 0.9, 테 1.0, 반사 0.7, 폭 ×1.15, 호 전체가 앞으로 약 4px 기울어(OFFSET_Y) **어깨를 들이민 자세**.
- **종료 END ≈0.4초**: 호가 차체 쪽으로 접히며(배율 1.0→0.7) 페이드. 레이서 교대·피트·차 제거는 강제 정리.

### 3-2. 배틀 시작 `talent.wheel_to_wheel_surge` (≈0.55초, 1회)
- 앞코에서 **흰 압력 반달(앞으로 볼록)**이 튀어 나가며 커지고 사라짐: 앞으로 약 20px(상대까지 거리 40~60의 절반쯤) 이동, 배율 0.6→1.4, 0.45초. ALPHA 본체 + ADDITIVE 테.
- 앞코 흰 섬광 0.2초.
- 앞 양 모서리 노란 불티 BURST 각 4개(앞·바깥으로).
- 같은 0.3초 동안 LOOP의 `battle_engaged`가 함께 올라가므로 호가 앞으로 기우는 동작과 이어진다.
- 상대 차에는 아무것도 붙이지 않는다(상대는 차 길이 1배 정도 앞 — 빈 노면에 뜬 표시가 됨).

### 3-3. 막혔는데 버팀 `talent.wheel_to_wheel_grind_left` / `_right` (≈0.6초, 1회)
이름의 left/right는 **상대가 있는 쪽**이다. 예: `_left` = 상대가 내 왼쪽 앞, 나는 오른쪽으로 빠짐.
- 상대 쪽 앞 모서리에 **노랑-흰 불꽃 분수**(부채꼴 그림 1장, 뒤·바깥으로 퍼짐, 0.4초) + **흰 섬광 별**(0.2초) + 불티 BURST 8개.
- 반대쪽(빠져나가는 쪽)으로 **흰 압력 반달이 옆으로 차고 나감**(0.35초, 약 10px).
- LOOP 호의 상대 쪽 테도 같은 시간 번쩍이면 좋지만 TEXTURED_SPRITE 한 장이 좌우를 같이 그려 한쪽만은 안 된다 → 이 package의 테 번쩍임이 대신한다.
- 쪽 고르기(③, VFX 연결 컨트롤러): 신호의 `front`와 내 차선 차(`front.current_lane_offset − current_lane_offset`)의 부호. 거의 같으면 차선 변경 방향(`target_lane_offset − current_lane_offset`)의 반대쪽. 둘 다 0이면 `_right`. 화면 좌우와 차선 부호의 관계는 ③에서 실제 트랙으로 확인.
- 기능 세션 변경 없이 public 값만 읽는다.

### 3-4. 순간 연출을 상대 차(접촉 지점)에 둘까? → **두지 않는다(권장)**
1. 판정 순간 거리 차가 0~60이라 대부분 실제로 닿아 있지 않다. 두 차 사이 "접촉 지점"에 두면 빈 노면에 불꽃이 뜬다.
2. 상대 뒷범퍼 표식은 체인 바인드 족쇄가 쓰고 있다. 상대에 붙이면 "누가 재능을 썼는지"가 헷갈린다(8대 NPC 상황).
3. 그래서 **내 차의 상대 쪽 앞 모서리**에 둔다. 부채꼴이 상대 쪽·뒤로 퍼지므로 실제로 붙어 있을 때는 두 차 사이에서 터진 것처럼 보이고, 떨어져 있을 때도 어색하지 않다.

### 3-5. 동시 발생·간격
- `battle_start`와 `hold_resisted`가 같은 틱이면 둘 다 재생한다(앞으로 압력파 + 모서리 불꽃 — 겹쳐도 역할이 다름).
- 같은 package가 다시 오면 **이전 것을 정리하고 새로 시작**(쌓지 않음). 최소 간격 0.4초(그 안의 신호는 무시).
- 플레이어 화면 효과 없음.

## 5. 새 기능 범위

### 새 runtime 입력 `battle_engaged`
- 0~1, 기본 0. `get_wheel_to_wheel_visual_state().in_battle`(내가 뒤차로 배틀 중)을 Game이 부드럽게(올림 약 0.1초, 내림 약 0.4초) 만든다. `drift_active`·`boost_active`와 같은 방식.
- Studio: 스키마 `x_vfx_runtime_inputs`에 추가, preview에 슬라이더 + Battle 토글.
- Game ③: 공급자(선언한 effect만 평가). 기능 세션 변경 없음(이미 `in_battle` 있음).
- 이름은 일반 의미(배틀 중)라 다른 재능도 쓸 수 있다.

### 그 밖
- 순간 package 3개는 기존 기능(START만 있는 1회 package: TEXTURED_SPRITE + PARTICLE BURST)으로 만든다. 새 레이어 타입 없음.
- 불티는 기존 `fx.furious_overtake_spark`를 레몬 노랑으로 곱해 재사용(체인 바인드는 호박색 — 색으로 구분). 크기는 80 이상(작으면 경기 화면에서 안 보임 — 스노우 보더 교훈).

## 6. 기능 세션(게임) 쪽

- 추가 작업 요청 없음. 위 신호·읽기 함수와 public 차선 값으로 충분하다.
- 측정(기능 세션 남은 일 1번)에서 함께 받을 값: 발동 1회당 `battle_start`·`hold_resisted` 횟수, 두 신호 사이 간격 분포, `in_battle` 시간 비율, `hold_resisted` 때 앞차와의 거리·차선 차 분포.
- 이름이 바뀌면 이 문서와 ③ 연결을 같이 고친다.

## 11. 유지 연출 v2 — 흐르는 난기류 결 (2026-11-27, 시안 단계)
- 지훈 피드백: 옆 흰 반달이 너무 또렷하고 가만히 있어서 바람으로 안 보이고, 여러 대면 흰 덩어리가 된다.
- 방향(지훈 승인): 고정 띠 대신 짧은 결이 앞 문짝 옆에서 생겨 뒤로 흘러가다 차 뒤끝에서 흩어진다. 따뜻한 흰색 + 노란 불티. 좌우 구분은 1차에서 하지 않는다.
